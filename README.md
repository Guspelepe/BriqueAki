# TrocaTudo / BriqueAki

Site de trocas com moedas, chat, localização e avaliações.

## 🚀 Como rodar o projeto

### 1. Pré-requisitos
- Node.js instalado (ou Python)
- Git instalado

### 2. Configurar a chave da API do Google Maps
1. Copie o arquivo `config.example.js` para `config.js`
2. Cole sua chave do Google Maps no arquivo `config.js`

### 3. Instalar dependências
```bash
npm install http-server -g
